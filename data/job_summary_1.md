Description
Data Engineer with Analytics Engineering focus

Summary
Join Instabee’s new Data Platform team in Stockholm as a Data Engineer who also bridges analytics engineering. You’ll build and evolve a GCP‑Snowflake data platform, integrating diverse sources, automating pipelines, and modelling data with DBT and Python. The role blends infrastructure, data product principles, and stakeholder collaboration in an agile, hybrid environment. Benefits include a sky‑high office, pet‑friendly floors, tech breakfasts, flexible hours, and generous parental and birthday leave.

Responsibilities
Design and implement modern data platform on GCP and Snowflake, create integration patterns, build and migrate source connections (APIs, MongoDB, MySQL), set up CI/CD and IaC, orchestrate pipelines with Airflow, model data using DBT, SQL, Python, ensure data discoverability and trust, collaborate with stakeholders, support analytics projects, maintain platform infrastructure.
